# U3c Games Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Match and Speed round games from a deck's cards that earn XP.
**Architecture:** `game_plays` table feeds `activity_by_day.games` and `dayXp`; pure builders in `lib/games`; two client components on a play page.
**Tech Stack:** Supabase SQL, TypeScript, React 19, Vitest, Playwright.
**Spec:** docs/superpowers/specs/2026-10-11-u3c-games-design.md

## Global Constraints
8 XP per game, max 3 per day; no timers; games never touch card scheduling; minimum 4 cards; words not colour alone for right/wrong.

## Review Focus
Repeated card backs; deck deleted mid-game; save failure still shows results; more than 3 plays a day earns no extra; another student's plays never counted.
