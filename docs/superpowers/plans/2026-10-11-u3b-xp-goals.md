# U3b XP, Levels and Daily Goals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Show XP, a level, three daily goals and a study streak, worked out from data the app already stores.

**Architecture:** One read-only SQL function `activity_by_day(p_tz)` returns per-day counts; a pure library `lib/xp` turns them into XP, level, goals and streak; a hook loads them; Home and Progress show them.

**Tech Stack:** Supabase SQL, TypeScript, React 19, Vitest, Playwright.

**Spec:** docs/superpowers/specs/2026-10-11-u3b-xp-goals-design.md

## Global Constraints

- Rules table, level formula (`floor(sqrt(xp/50))+1`), goal targets (10 cards, 25 focus minutes, 1 quiz) and bonus (20) exactly as in spec section 4.
- No new tables. Days use the profile time zone. No animation. Done states never colour alone.

## Review Focus

- Invalid time zone: lookup fails, Home and Progress still render without XP parts.
- Midnight boundary: the same record lands on different days in different zones.
- Other users' rows are never counted.
- Today empty: streak continues from yesterday.
- XP never negative or NaN when counts are zero.
